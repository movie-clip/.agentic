# Network lint runs

One directory per run that lints edits to the network's own files:
`<YYYY-MM-DD>-<slug>/`. `run.md` is the ledger; the `protocol-lint` reports
beside it are what `scripts/check_network_edit.py` looks for.

How such a run works: `protocol/authoring.md` § "Linting a network edit".
Retention: `protocol/orchestrator.md` § "Closed runs are pruned".
